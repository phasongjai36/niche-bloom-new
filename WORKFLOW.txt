============================================================
NICHE BLOOM — สรุปขั้นตอนการทำงานของโปรเจค (WORKFLOW)
============================================================

[1] โครงสร้างและบทบาทไฟล์
- index.html    : โครงหน้าจอทั้ง 5 แท็บ (แดชบอร์ด/ใบเสร็จ/ทวงถาม/ประวัติ/ตั้งค่า)
- app.js        : ตรรกะทั้งหมด — ต่อ Supabase, คำนวณสถิติ, สร้าง QR พร้อมเพย์,
                  สร้างใบเสร็จ, ดาวน์โหลด PNG, กราฟรายเดือน, สลับธีม
- styles.css    : ธีม "Night Botanical" (กลางคืน/กลางวัน) ควบคุมผ่านตัวแปร CSS
- assets/       : โลโก้พวงดอกไม้ (logo.png) และเวอร์ชันสีทอง (logo-gold.png)
- import-data.py: นำเข้าข้อมูลลูกค้า/สัญญาจากไฟล์ Excel เข้า Supabase
- api/          : LINE webhook + ส่งแจ้งเตือน (deploy เป็น Vercel functions)
- vercel.json   : ค่า deploy บน Vercel

[2] ข้อมูลเก็บที่ไหน
- ข้อมูลลูกค้า/สัญญา/ประวัติการชำระ เก็บบน Supabase (cloud) ไม่เก็บในเครื่อง
- รหัสเชื่อมต่อ Supabase ฝังใน app.js (anon key — ปลอดภัยเพราะมี RLS กำกับ)
- ตั้งค่าธีม (มืด/สว่าง) เก็บใน localStorage ของเบราว์เซอร์

[3] ขั้นตอนเริ่มใช้งาน (เครื่องใหม่)
1) เปิดโฟลเดอร์โปรเจค
2) รัน: python import-data.py          (ดูตัวอย่างก่อน = dry run)
3) รัน: python import-data.py --apply  (นำเข้าจริงเข้า Supabase)
4) รันเซิร์ฟเวอร์: python -m http.server 4173
5) เปิดเบราว์เซอร์: http://localhost:4173

[4] การทำงานประจำวัน
- แดชบอร์ด: เห็นภาพรวม สัญญาครบกำหนดวันนี้/เลยกำหนด/ยอดค้าง + กราฟ 6 เดือน
- สร้างใบเสร็จ: เลือกลูกค้า > เลือกงวด > สร้างใบเสร็จ + QR > พิมพ์ / ดาวน์โหลด PNG
- ทวงถาม: ระบบคิดค่าปรับอัตโนมัติ แก้ค่าปรับได้ กด "ชำระแล้ว" หรือส่งแจ้งเตือน LINE
- ประวัติ: ใบเสร็จทั้งหมด กรองตามสถานะตรวจสอบ
- ตั้งค่า: เลขพร้อมเพย์ เลขบัญชี ค่าปรับเริ่มต้น ชื่อแบรนด์

[5] Git / GitHub
- รีโมต: github.com/phasongjai36/niche-bloom-new (branch main)
- main ปัจจุบัน = แอป Electron/React (เวอร์ชันใหม่) + โฟลเดอร์ classic/
  ซึ่งเป็นแดชบอร์ด HTML/JS ตัวนี้ที่ merge ผ่าน PR #4 แล้ว (squash 1919be1)
- เวอร์ชัน deploy จริงบน Vercel คือตัวนี้ (classic) — เข้าถึงได้จากโฟลเดอร์ทั้งใน
  main (classic/) หรือโฟลเดอร์เดิมในเครื่อง

[6] ข้อควรรู้
- ถ้าแดชบอร์ดขึ้น "—" หรือโหลดไม่ได้ = เน็ต/Supabase ไม่ถึง ไม่ใช่ข้อมูลหาย
- ธีมมืดเป็นค่าเริ่มต้น กดปุ่มพระจันทร์/พระอาทิตย์มุมขวาบนเพื่อสลับ (จำค่าไว้ให้)
- ใบเสร็จที่ดาวน์โหลดเป็น PNG จะเป็นกระดาษสีครีมเสมอ แม้ตอนใช้ธีมมืด (ตั้งใจให้เป็นเอกสาร)
- ห้ามใส่ข้อมูลลูกค้าผ่าน innerHTML โดยไม่ผ่าน esc()/escJs() ใน app.js (กัน XSS)
